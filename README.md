## 📥 Как использовать конфигурацию

1. **Скопируйте конфигурацию** — share-ссылку из каталога [configs/](configs/) или ссылку на файл подписки [subscriptions/](subscriptions/).
2. **Откройте совместимый VPN-клиент** — тот, что поддерживает нужный вам протокол (VLESS, Reality, Hysteria2, Shadowsocks или Trojan).
3. **Импортируйте конфигурацию** — через буфер обмена или добавив ссылку подписки в настройки клиента.
4. **Обновляйте подписку** — периодически обновляйте список узлов в клиенте, чтобы получать актуальные конфигурации.

## 🔄 Автоматическое обновление

Проект использует GitHub Actions ([.github/workflows/update.yml](.github/workflows/update.yml)), который ежедневно:

1. Загружает конфигурации из разрешённых публичных источников ([sources/](sources/README.md)).
2. Проверяет формат ссылок (VLESS, VMess, Reality, Hysteria2, Shadowsocks, Trojan).
3. Удаляет дубликаты конфигураций.
4. Выполняет базовую проверку доступности узлов и отфильтровывает недоступные.
5. Распределяет конфигурации по протоколам и обновляет файлы подписок.
6. Обновляет статистику в этом README и автоматически коммитит изменения.

## ❓ FAQ

### Что такое бесплатный VPN?

Это VPN-подключение, за которое не требуется платить. В данном проекте бесплатный VPN — это набор публичных конфигураций (VLESS, Reality, Hysteria2, Shadowsocks, Trojan), которые можно импортировать в совместимый VPN-клиент.

### Почему конфигурация перестала работать?

Бесплатные узлы могут отключаться, менять адрес или достигать лимита подключений. Если конфигурация больше не подключается, попробуйте другую конфигурацию из того же каталога или обновите подписку.

### Как обновить подписку?

В большинстве VPN-клиентов есть кнопка «Обновить подписку» в разделе со списком узлов. Ссылку на подписку можно взять из каталога [subscriptions/](subscriptions/) или получить у Telegram-бота [@ru_hight_vpn_bot](https://t.me/ru_hight_vpn_bot).

### Что такое VLESS?

VLESS — это лёгкий прокси-протокол без встроенного шифрования: оно обеспечивается транспортным слоем (например, TLS). Подробнее — в [docs/vless.md](docs/vless.md).

### Что такое Reality?

Reality — это технология маскировки TLS-соединения, работающая поверх VLESS. Она позволяет серверу представляться обычным HTTPS-сайтом без собственного домена и сертификата. Подробнее — в [docs/reality.md](docs/reality.md).

### Что такое Hysteria2?

Hysteria2 — это прокси-протокол на базе QUIC (UDP), разработанный для нестабильных сетей с потерями пакетов. Подробнее — в [docs/hysteria2.md](docs/hysteria2.md).

### Чем отличаются VPN-протоколы?

Протоколы различаются транспортном (TCP/UDP), способом маскировки трафика и требованиями к серверу. Shadowsocks и Trojan работают поверх TCP, Hysteria2 — поверх QUIC/UDP, VLESS и Reality — современные протоколы с гибкой настройкой транспорта. Обзор — в [docs/vpn-configs.md](docs/vpn-configs.md).

### Можно ли использовать конфигурации на Android?

Да, если ваш VPN-клиент поддерживает соответствующий протокол. Подробности — в [docs/vpn-android.md](docs/vpn-android.md).

### Можно ли использовать конфигурации на iPhone?

Да, если выбранный VPN-клиент поддерживает нужный протокол. Подробности — в [docs/vpn-iphone.md](docs/vpn-iphone.md).

### Можно ли использовать конфигурации на Windows?

Да, конфигурации работают в любых совместимых клиентах для Windows. Подробности — в [docs/vpn-windows.md](docs/vpn-windows.md).
