# Hysteria2 конфигурации

В этом каталоге размещаются проверенные бесплатные Hysteria2-конфигурации.

## Содержимое

- `verified.txt` — share-ссылки конфигураций, прошедших валидацию формата и проверку доступности. Файл создаётся автоматически и появляется здесь только при наличии проверенных конфигураций.

## Формат конфигурации

Share-ссылка Hysteria2 выглядит так (значения в угловых скобках — заполнители):

```
hysteria2://<auth>@<host>:<port>?sni=<domain>&insecure=<0|1>&obfs=<obfs>&obfs-password=<password>#<name>
```

## Как использовать

Скопируйте share-ссылку и импортируйте её в совместимый VPN-клиент, поддерживающий Hysteria2. Подробнее — в [docs/hysteria2.md](../../docs/hysteria2.md).

Подписка: [subscriptions/hysteria2.txt](../../subscriptions/hysteria2.txt).
