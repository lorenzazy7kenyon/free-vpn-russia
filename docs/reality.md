# Reality VPN-конфигурации

Reality (REALITY) — технология маскировки TLS-соединений, работающая поверх VLESS. Бесплатные Reality-конфигурации — один из самых востребованных типов конфигураций в этом проекте.

## Что такое Reality

Reality — это расширение протокола VLESS, при котором сервер при TLS-рукопожатии «отзеркаливает» настоящий TLS-сайт указанного домена (`sni`). Со стороны соединение выглядит как обычный HTTPS-запрос к этому сайту, при этом для клиента, знающего правильный публичный ключ, работает прокси-туннель.

Ключевое отличие от обычного TLS: серверу Reality не нужен собственный домен и TLS-сертификат — он использует «отпечаток» другого сайта.

## Основные особенности

- работает поверх VLESS;
- не требует домена и сертификата от владельца сервера;
- маскирует соединение под HTTPS к популярному сайту;
- использует пары ключей x25519 (`pbk` — публичный ключ, `sid` — short id);
- обычно применяется с `flow=xtls-rprx-vision` и `fp=chrome` (отпечаток клиента).

## Формат конфигурации

Share-ссылка VLESS + Reality (значения в угловых скобках — заполнители):

```
vless://<uuid>@<host>:<port>?encryption=none&security=reality&sni=<domain>&fp=chrome&pbk=<publickey>&sid=<shortid>&type=tcp&flow=xtls-rprx-vision#<name>
```

Обязательные параметры Reality:

| Параметр | Значение |
|---|---|
| `security` | `reality` |
| `pbk` | публичный ключ сервера, 43 символа base64url |
| `sni` | домен, под который маскируется соединение |
| `sid` | short id (опционально, hex) |

## Как импортировать

1. Скопируйте Reality share-ссылку из [configs/reality/](../configs/reality/).
2. Откройте совместимый VPN-клиент с поддержкой Reality (протокол VLESS + security=reality).
3. Импортируйте ссылку через буфер обмена и подключитесь.

Инструкции по платформам: [Android](vpn-android.md), [iPhone](vpn-iphone.md), [Windows](vpn-windows.md).

## Частые вопросы

**Нужен ли Reality на iPhone/Android?** Да — клиент должен поддерживать протокол VLESS с security=reality; старые версии клиентов могут не распознавать такие ссылки.

**Чем Reality лучше обычного TLS?** Reality не требует сертификата и выглядит как соединение с чужим популярным сайтом. Но «лучше» — не значит «всегда доступнее»: доступность зависит от конкретного сервера и сети.

**Ошибка «pbk invalid»?** Ссылка повреждена при копировании — скопируйте её целиком, без переносов строк.
