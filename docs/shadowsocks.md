# Shadowsocks VPN-конфигурации

Shadowsocks — классический шифрованный прокси-протокол с простой конфигурацией. Бесплатные Shadowsocks-конфигурации — один из самых распространённых типов публичных конфигураций.

## Что такое Shadowsocks

Shadowsocks — это легковесный шифрованный прокси, созданный в 2012 году. Клиент шифрует трафик выбранным методом и передаёт его на сервер, сервер расшифровывает и пересылает запросы в интернет.

## Основные особенности

- симметричное шифрование выбранным методом;
- рекомендуемые современные методы — AEAD: `aes-256-gcm`, `chacha20-ietf-poly1305`, а также семейство `2022-blake3-*` (Shadowsocks 2022);
- простая конфигурация: метод, пароль, адрес и порт;
- работают поверх TCP (плюс отдельная UDP-релей поддержка);
- нет встроенной маскировки под HTTPS (для этого есть плагины, например `v2ray-plugin`).

## Формат конфигурации

Share-ссылка Shadowsocks (значения в угловых скобках — заполнители):

```
ss://<base64(method:password)>@<host>:<port>#<name>
```

| Часть | Значение |
|---|---|
| `method` | метод шифрования, например `aes-256-gcm` |
| `password` | пароль |
| `host:port` | адрес сервера |

Проект принимает только известные методы шифрования; устаревшие и небезопасные методы отбраковываются при валидации.

## Как импортировать

1. Скопируйте `ss://` ссылку из [configs/shadowsocks/](../configs/shadowsocks/).
2. Откройте совместимый VPN-клиент, поддерживающий Shadowsocks.
3. Импортируйте ссылку через буфер обмена и подключитесь.

Инструкции по платформам: [Android](vpn-android.md), [iPhone](vpn-iphone.md), [Windows](vpn-windows.md).

## Частые вопросы

**Какой метод шифрования выбрать?** Из современных — `aes-256-gcm` или `chacha20-ietf-poly1305`; если сервер поддерживает Shadowsocks 2022 — методы `2022-blake3-*`.

**Почему соединение «виснет»?** Возможно, сервер недоступен или порт ограничен. Проверьте статус узла в таблице статистики [README](../README.md) и попробуйте другой узел.

**Чем Shadowsocks отличается от Trojan?** Trojan маскирует трафик под обычный HTTPS-запрос, Shadowsocks использует собственный шифрованный формат без имитации TLS.
