# VLESS VPN-конфигурации

VLESS — это современный лёгкий прокси-протокол, разработанный командой Project X как развитие протокола VMess. Бесплатные VLESS-конфигурации — один из основных типов конфигураций в этом проекте.

## Что такое VLESS

VLESS — протокол прикладного уровня, который передаёт трафик между клиентом и сервером почти без накладных расходов. В отличие от VMess, VLESS не шифрует данные сам: шифрование обеспечивает транспортный слой — обычно TLS или Reality.

## Основные особенности

- минимальные накладные расходы на протокол;
- шифрование обеспечивается TLS/Reality, а не самим протоколом;
- поддержка разных транспортов: `tcp`, `ws` (WebSocket), `grpc`, `httpupgrade`;
- поддержка `flow` (например, `xtls-rprx-vision`) для контроля трафика;
- аутентификация по UUID.

## Формат конфигурации

Share-ссылка VLESS (значения в угловых скобках — заполнители):

```
vless://<uuid>@<host>:<port>?encryption=none&security=<none|tls|reality>&sni=<domain>&fp=chrome&type=<tcp|ws|grpc>&path=<path>&flow=<flow>#<name>
```

Ключевые параметры:

| Параметр | Значение |
|---|---|
| `uuid` | идентификатор пользователя (UUIDv4) |
| `security` | `none`, `tls` или `reality` |
| `sni` | домен, предъявляемый при TLS-рукопожатии |
| `type` | транспорт: tcp, ws, grpc и др. |
| `flow` | управление потоком, например `xtls-rprx-vision` |

## Как импортировать

1. Скопируйте VLESS share-ссылку из [configs/vless/](../configs/vless/) или получите её в Telegram-боте.
2. Откройте совместимый VPN-клиент, поддерживающий VLESS.
3. Выберите «Импорт из буфера обмена» или «Добавить конфигурацию» и вставьте ссылку.
4. Подключитесь и проверьте соединение.

Инструкции по платформам: [Android](vpn-android.md), [iPhone](vpn-iphone.md), [Windows](vpn-windows.md).

## Частые вопросы

**Чем VLESS отличается от VMess?** VLESS проще и легче: у него нет собственного слоя шифрования и «лишних» заголовков, шифрование выполняет TLS/Reality.

**Обязательно ли нужен TLS?** Рекомендуется: без TLS (`security=none`) трафик не шифруется транспортным слоем. Публичные конфигурации с `security=none` стоит использовать с осторожностью.

**Что значит `security=reality`?** Это VLESS с маскировкой Reality — см. [reality.md](reality.md).
