# Бесплатные VPN-конфигурации

В этом документе описано, какие бесплатные VPN-конфигурации собраны в проекте, как их получить, скопировать и обновлять.

## Какие протоколы есть в проекте

| Протокол | Особенности | Документация |
|---|---|---|
| **VLESS** | Лёгкий протокол, шифрование на транспортном уровне (TLS) | [vless.md](vless.md) |
| **Reality** | VLESS + маскировка TLS-отпечатка, не требует собственного домена у клиента | [reality.md](reality.md) |
| **Hysteria2** | Транспорт QUIC/UDP, устойчив к потерям пакетов | [hysteria2.md](hysteria2.md) |
| **Shadowsocks** | Классический шифрованный прокси, простая конфигурация | [shadowsocks.md](shadowsocks.md) |
| **Trojan** | Трафик выглядит как обычный HTTPS | [trojan.md](trojan.md) |

## Где находятся конфигурации

- [configs/](../configs/) — каталоги по протоколам: [vless](../configs/vless/), [reality](../configs/reality/), [hysteria2](../configs/hysteria2/), [shadowsocks](../configs/shadowsocks/), [trojan](../configs/trojan/).
- [subscriptions/](../subscriptions/) — файлы подписок: [all.txt](../subscriptions/all.txt), [vless.txt](../subscriptions/vless.txt), [reality.txt](../subscriptions/reality.txt), [hysteria2.txt](../subscriptions/hysteria2.txt), [shadowsocks.txt](../subscriptions/shadowsocks.txt), [trojan.txt](../subscriptions/trojan.txt).

Конфигурации публикуются только после автоматической проверки: сначала валидация формата, затем базовая проверка доступности узла (TCP-подключение с измерением задержки).

## Как получить конфигурацию

1. Откройте каталог нужного протокола в [configs/](../configs/) или таблицу статистики в [README](../README.md).
2. Выберите узел со статусом `reachable` при последней проверке.
3. Скопируйте share-ссылку из файла `verified.txt`.

## Как скопировать конфигурацию

- На GitHub откройте файл `verified.txt` нужного протокола и скопируйте нужную строку целиком — это share-ссылка вида `vless://...`, `hysteria2://...` и т.п.
- Для подписки скопируйте raw-ссылку на файл подписки (кнопка **Raw** на странице файла) — её добавляют в поле «URL подписки» в VPN-клиенте.

## Как обновить конфигурации

Конфигурации в проекте обновляются автоматически: ежедневно workflow проверяет источники, отбирает рабочие конфигурации и перезаписывает файлы подписок. С вашей стороны достаточно:

1. добавить файл подписки в VPN-клиент один раз;
2. периодически нажимать «Обновить подписку» в клиенте.

Если вы используете отдельные share-ссылки, следите за изменениями в репозитории — устаревшие конфигурации заменяются или удаляются.
