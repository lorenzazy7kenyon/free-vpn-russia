# VPN для Windows

Как использовать бесплатные VPN-конфигурации на Windows: скопировать конфигурацию, импортировать её в совместимый VPN-клиент, обновлять подписку и проверять подключение.

## Требования

- компьютер с Windows 10/11;
- совместимый VPN-клиент, поддерживающий нужный протокол: [VLESS](vless.md), [Reality](reality.md), [Hysteria2](hysteria2.md), [Shadowsocks](shadowsocks.md) или [Trojan](trojan.md);
- конфигурация из [configs/](../configs/) или файл подписки из [subscriptions/](../subscriptions/).

Проект не привязан к конкретному приложению — подойдёт любой поддерживаемый VPN-клиент с нужным протоколом.

## Как скопировать конфигурацию

1. Откройте каталог нужного протокола, например [configs/vless/](../configs/vless/).
2. Откройте файл `verified.txt` и скопируйте share-ссылку целиком (одна строка — одна конфигурация).
3. Для подписки скопируйте raw-ссылку на файл из [subscriptions/](../subscriptions/) (кнопка **Raw** на GitHub).

## Как импортировать конфигурацию

1. Откройте VPN-клиент на Windows.
2. Нажмите «Добавить сервер» или «Импорт из буфера обмена» (Ctrl+V).
3. Вставьте share-ссылку или добавьте подписку по URL.
4. Сохраните профиль и выберите его в списке серверов.

## Как обновить подписку

В клиенте откройте раздел «Подписки» и нажмите «Обновить». Файлы подписок проекта обновляются автоматически, поэтому после синхронизации в клиенте появятся актуальные конфигурации. Можно включить автопериодическое обновление в настройках клиента.

## Как переключить узел

Выберите другой сервер из списка профиля-подписки. Задержка и доступность различаются в зависимости от сервера, вашего провайдера и времени суток; многие клиенты показывают тест задержки (ping) по списку узлов.

## Как проверить подключение

1. Включите подключение в клиенте (системный прокси или режим TUN — в зависимости от клиента).
2. Откройте любой сайт и убедитесь, что он загружается.
3. При необходимости проверьте свой внешний IP-адрес любым сервисом проверки IP — он должен соответствовать расположению сервера, к которому вы подключены.

## Частые вопросы

**Интернет пропал после включения клиента?** Отключите режим прокси/TUN в клиенте или сбросьте настройки прокси Windows (Параметры → Сеть и Интернет → Прокси).

**Антивирус ругается на клиент?** Используйте клиенты из официальных источников и проверяйте дистрибутивы.
