# Источники конфигураций

В этом каталоге описаны публичные источники, которые проект использует для получения бесплатных VPN-конфигураций.

## Правила

1. Добавляйте только те источники, которые **публично и бесплатно** распространяют конфигурации.
2. Если лицензия или условия использования источника неясны — **не добавляйте его** и не включайте автоматический сбор.
3. Все источники перечисляются в файле [sources.json](sources.json). Источник с URL-заглушкой `SOURCE_URL` или с `"enabled": false` скриптом игнорируется.
4. Токены, ключи и секреты в код не записываются — при необходимости используйте GitHub Secrets.

## Формат записи

| Поле | Описание |
|---|---|
| Название | Имя источника |
| URL | Адрес источника (`SOURCE_URL` — заглушка) |
| Тип данных | `base64` (дамп подписки) или `plain` (список share-ссылок) |
| Включён | `true` / `false` — участвует ли источник в автосборе |
| Последнее обновление | Дата последней успешной загрузки |
| License / условия | Известные условия использования (если есть) |

## Как добавить источник

1. Убедитесь, что источник публично разрешает использование своих конфигураций.
2. Заполните запись в [sources.json](sources.json) и поставьте `"enabled": true`.
3. Дождитесь планового запуска workflow (ежедневно) или запустите его вручную через вкладку **Actions → Update VPN configurations → Run workflow**.
4. После проверки конфигурации появятся в [subscriptions/](../subscriptions/) и в статистике README — только если прошли валидацию и проверку доступности.
